# KISA Python 시큐어코딩 가이드 (2023년 개정본)

KISA가 공공·민간 개발자에게 제공하는 **47개 Python 보안약점** 가이드를 기반으로 한 룰 모음입니다.

## 출처
- **발행**: 한국인터넷진흥원(KISA), 2023년 개정본
- **원문**: Python 시큐어코딩 가이드(2023년 개정본) PDF, 170페이지
- **저작권**: 정부 가이드, 인용·재구조화 형태. 본문 전체 복제 금지

## 카테고리 구성 (원문 기준)

| 절 | 카테고리 | 항목 수 | 본 디렉토리 룰 |
|---|---|---|---|
| 제2절 | 입력데이터 검증 및 표현 | 16 | KISA-PY-INPUT-* |
| 제3절 | 보안기능 | 16 | KISA-PY-SEC-* |
| 제4절 | 시간 및 상태 | 2 | KISA-PY-TIME-* |
| 제5절 | 에러처리 | 3 | KISA-PY-ERR-* |
| 제6절 | 코드오류 | 3 | KISA-PY-CODE-* |
| 제7절 | 캡슐화 | 4 | KISA-PY-ENCAP-* |
| 제8절 | API 오용 | 3 | KISA-PY-API-* |

**현재 룰 수**: 5 (시범 단계, INPUT 4 + SEC 1)

## 행안부 MOIS-49와의 관계
KISA 가이드는 행안부 SW 개발보안 가이드의 49 보안약점을 **Python 특화 코드 예시**로 보강한 형태입니다.
- 같은 보안약점은 `related_baseline`에 MOIS-49-* ID를 명시
- KISA 룰은 *코드 검출 패턴*에 집중, MOIS-49는 *원리 설명*에 집중

## 시범 단계 (2026-05-31)
입력 검증 카테고리(가장 검출 가치 높음) + 보안기능 일부로 시작. 검출 패턴이 안정되면 나머지 항목 단계적으로 추가합니다.
