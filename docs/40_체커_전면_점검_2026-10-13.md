## 0. 한 줄 요약

- 오탐이 반복되는 이유는 룰이 아니라 **엔진의 구조**다: JS 는 파서 없이 정규식으로 문법을 흉내
  내고(1,350줄, 괄호·문자열 워커 11벌), Python 은 "출처"가 아니라 "조립 모양"에서 출발해 출처를
  나중에 덧붙였으며, 판정 계층(룰 기본값·프로파일·감쇄 10종·근거 정책)이 서로 다른 예외 목록을 쓴다.
- 더 급한 것은 **미탐**이다. `'…{name}'.format(name=request.args['n'])`, SQLAlchemy `text()`,
  `for row in cur.execute(…)`, `req.query.id`, `x || \`<p>…</p>\``, `.env` 파일, 여러 줄 빈 `catch`,
  `AWS_SECRET_ACCESS_KEY = "…"` 가 **발견 0건**이다(재현). 오탐은 사람이 걸러낼 수 있지만 미탐은 못 본다.
- 운영: 포털이 **한 달 묵은 위협 인텔**로 판정하고 있었다(KEV 1,709 → 1,739, 신규 30건 미반영).
  GitHub 일일 번들은 정상이었고 받는 쪽(`scan` 은 자동 갱신 안 함, 기준 30일)이 문제였다. 수동 동기화로 해소.
- 공공 공식 도구로 쓰려면: 위 미탐 묶음 → 판정 계층 단일화 → 감사 추적(감쇄 이력·예외 승인) →
  JS 파서 → 실제 소스 정밀도 게이트 순. Python 은 가깝고, TypeScript 는 파서 없이는 멀다.

## 1. 스패로우는 다 보는데 우리는 왜 안 보나 — 답

성능 때문이 아니다. 정규식 룰 101개는 지원 파일의 **모든 줄**에 다 댄다. 다른 점은 둘이다.
① 룰이 없는 파일 형식(`.ps1`·`.iss`·`.htaccess`·`.jsp`·이미지 등)과 생성·압축·벤더 파일은 애초에
안 보고 "검사 안 함"으로 적는다. ② 같은 `innerHTML` 이라도 값이 상수·정화된 것은 출처 추적으로
걸러 보고서에 올리지 않는다(스패로우는 211건을 전부 올린다). 즉 **오탐을 줄이려는 선택**이다.
대신 스패로우는 20개 언어 1,420개 체커로 넓고 얕게, 우리는 Python·JS·TS·HTML 101개 룰로 좁고 깊게 본다.
그런데 ①의 "룰이 없는 파일"에 `.env` 같은 비밀 위치가 들어가 있었다(§3-1) — 선택이 아니라 결손이다.

## 3. 미탐 (재현된 것만 · 전부 "발견 0건" 또는 등급 하락)

### 3-1. 파일·전처리 단계
- **`.env`·`.env.local`·`.env.production` 이 한 번도 검사되지 않음** — `Path('.env').suffix == ''`. `.npmrc`·`.pypirc`·`.netrc`·`.htpasswd`·`web.config`·`.jsp/.ejs/.hbs/.ipynb` 도 같음. 비밀값이 가장 흔히 있는 자리다.
- `/**/ el.innerHTML = location.hash;` — `/*` 로 시작하면 줄 전체를 주석으로 봐 **우회 가능**.
- 거대 JSON 리터럴 한 줄(3,158자 `const CATALOG=[…]`)이 있으면 **파일 전체** 제외(파노라마뷰 DEMO 페이지가 이 경우). `credentials.json` 한 줄 2,040자도 "빌드 산출물"로 제외돼 비밀 룰까지 꺼짐.
- `migration_20240101.js`·`backup-20251013.ts` 가 해시 파일명 규칙(`[.\-_][0-9a-f]{8,}`)에 걸려 조용히 제외. `openapi.spec.json`·`docs/spec/` 가 테스트 경로로 감쇄.
- `vendor/ third_party/ env/ coverage/` 는 제외 기록 없이 사라짐(주석 "조용히 버리지 않는다"와 모순).

### 3-2. Python AST
- **`'…{name}'.format(name=request.args['n'])`** — `expr_is_constant` 가 `.format` 의 키워드 인자를 안 봐 **상수**로 판정. 상수 템플릿 `TMPL.format(…)` 도 base 가 거부돼 없음. 정규식 예비망은 AST 파싱 성공 시 꺼지므로 **완전 미탐**(치명).
- sink 첫 인자가 Name/f-string/`+` 가 아니면 무시: `cur.execute(request.form['q'])`, `conn.execute(text(f"…{request.args['a']}"))`(SQLAlchemy — 공공 FastAPI 표준 형태), `cur.execute(q.strip())`, `' '.join(parts)`.
- sink 가 문장의 루트 식에만: `for row in cur.execute(…)`, `if cur.execute(…).fetchone()`, `with conn.execute(…) as r` 전부 없음.
- 분기에서 마지막 대입 승리: `if c: n = request.args['n'] else: n = 'd'` → 유력(차단 해제). `try/except` 기본값도 동일. `seen[key] = True` 가 `key` 의 출처를 지움.
- 명령 삽입은 1줄만 확인됨: `name = request.args['n']; os.system('ping ' + name)` → 유력·경고. 라우트 매개변수조차 경고.
- 중첩 함수·모듈 변수: `q = 'SELECT…' + request.args['n']` 를 다른 함수에서 실행 → 없음. `global TABLE` 로 다른 함수가 덮어써도 상수.
- sink 누락: `pandas.read_sql`, `exec_driver_sql`, `Model.objects.raw()`(정규식 경고만), `execute(sql=…)` 키워드.
- 출처 이름 과잉/과소: 변수명 `input` 이면 확인됨(`input = fh.read()` 도 차단), `@cache.get('k')` 가 라우트로 오인, `functions = [helper]` 가 도구 목록으로 오인; 반대로 `req.POST`, `self.request.query_params`, FastAPI `Query()/Body()`, `argparse` 결과는 출처로 안 봄.
- 상수 환경 소리 구멍: `conds += [dyn]`(AugAssign 이 컨테이너 실격 안 함), `COLS[0] = request…`(Subscript 저장 미탐), 내포식 타깃이 바깥 상수 이름과 충돌, `ph` 가 한 번 자리표시자면 뒤에 출처로 재대입돼도 상수.
- 죽은 코드: `_dynamic_part_is_a_parameter`·`_prompt_dynamic_part_is_a_parameter`·`_inherit_outer_constants`·`scope_params`·`_sql_rule_for` 둘째 인자·`_load_names(stmt.target)`. `_CONFIDENCE_BY_RULE` 주석이 사라진 함수를 설명한다.

### 3-3. JS 오염 추적
- **`el.innerHTML = req.query.id`** → 숫자 멤버 규칙(`.id`·`.date`…)이 출처 검사보다 먼저 평가돼 "HTML 이 될 수 없는 값" → **발견 삭제**. `req.params.id`·`req.body.date` 동일.
- **꼬리가 `.length` 면 식 전체가 상수**: `'<p>' + req.body.note + '</p> 총 ' + items.length` → 삭제.
- **템플릿 밖 피연산자 버림**: `data.html || \`<p>없음</p>\``, `ok ? \`<b>x</b>\` : data.note` → "보간 없는 템플릿" → 삭제.
- 선언이 같은 줄에서 연 `{` 스코프 안으로 기록: `const cfg = { title: location.hash }` → 못 찾음. 블록 화살표 `.map(r => {…}).join('')` 선언도 동일(prettier 기본 스타일 `.map(` 선행 체인도 추적 안 됨).
- `_ASSIGN_RE` 가 `let`/`const`/`var` 뒤 경계 없음: `letter = location.hash` 의 이름이 `ter`. `constraint`·`variables` 도.
- `if (…) {` 를 함수 스코프로 분류 → 같은 함수 안 순서 규칙이 깨져 상수 재할당도 차단(오탐). `try {` 는 다름. 여러 줄 템플릿 닫는 줄의 `}` 유실 → 이후 함수 전부 중첩.
- **2026-10-13 패치 회귀**: "인자가 출처면 확인됨"이 정화 헬퍼까지 TAINTED 로 — `rowHtml(data.row)`(본문에서 `esc`) 가 차단. 호출 모양 셋(`rowHtml(x)`·`.map(r=>rowHtml(r))`·`.map(rowHtml)`)이 세 답.
- TypeScript: `let html: string = req.body.note`(타입 주석) → 못 찾음. `data!.note`, `res?.data?.note`, `(r: Row): string =>`, 구조분해 `const { note } = req.body`, `export const` 전부 미추적. JSX `dangerouslySetInnerHTML` 은 js_taint 에 sink 가 없어 const/정화/오염 구분 없이 정규식 경고.
- sink 누락: jQuery `.html()/.append()/.after()` 0건, `insertAdjacentHTML(pos변수, x)` 정규식만. `textContent` 를 출처로 보고 `innerHTML` 되넣기는 미상(역전). `_TAINTED_NAME_RE` 부분 문자열(`draw`·`crawl`·`tbody`·`freq`·`jQuery`)로 '유력' 과잉.

### 3-4. 정규식 스캐너·룰
- **줄 단위 매칭이라 여러 줄 패턴 36개가 영구 무효**: 여러 줄 빈 `catch`, TOCTOU(`if exists:` ↵ `open`), 인가 누락 등. 999건 실측의 "ERR-03 119건"은 한 줄 `catch` 만 센 것.
- 비밀 룰 어휘가 좁음: `AWS_SECRET_ACCESS_KEY = "…"`, `PRIVATE_KEY = "…"`, `ENCRYPTION_KEY`, `signingKey`, YAML `secret_access_key:` 전부 0건. 마스킹 어휘(`redact_evidence`)는 아는데 탐지 어휘는 모름.

## 6. 공공기관 공식 보안도구로서의 평가 (Python·TypeScript 기준)

**갖춘 것**: KISA·행안부 룰 매핑(출처·CWE·안전 코드 예시), 룰셋 지문·설치 신원·재현 명령·소스 스냅샷,

**부족한 것(순서대로)**:

4. **TypeScript** — 타입 주석·`?.`·`!`·구조분해·제네릭·JSX sink 가 추적 밖. 전용 룰 0. 파서 없이는 "TS 지원"이라 말하기 어렵다.
5. **표준 결과표** — `Finding` 에 CWE 필드 없음(참고문헌 문자열), MOIS 49 항목별 결과표를 바로 못 만듦(스패로우는 만든다).
6. **측정** — 실제 소스 정밀도·재현율을 릴리스마다 재는 장치 없음.

결론: **Python 웹·배치 코드**는 §3-2·§3-4 의 미탐을 메우고 판정 계층을 단일화하면 보조 도구로 쓸 수 있다.
**TypeScript** 는 파서 도입(2층) 전까지는 "정규식 경고 + 사람 검토" 수준으로 한정해 안내해야 한다.

## 7. 수정 계획 (효과 순)

### A. 미탐부터 (1~2일, 파서 불필요)
1. `expr_is_constant` 의 `.format` 키워드 인자 검사 + `_expr_builds_dynamic_sql` 의 base 에 상수 이름 허용.
2. sink 인자 폴백을 `_reaches_source(식 전체)` 로, `text()`·`.strip()`·`.join()` 한 겹 벗기기, 루트 식을 `If.test/For.iter/With/Assert/Raise` 까지 확장, `read_sql`·`exec_driver_sql`·`raw()`·`execute(sql=)` sink 추가.
3. 명령 삽입을 `_process_scope` 의 `sourced` 와 연결(2줄·라우트 매개변수 확인됨).
4. 분기 합집합(`if/try` 블록을 복사본으로 돌린 뒤 합침), 대입 대상은 `_iter_names` 로 통일.
5. JS `classify_expr` 평가 순서: 출처 검사를 숫자·꼬리·백틱 분기보다 앞으로, 백틱 분기는 삼항·논리 분리 뒤로.
6. JS 선언 스코프를 "줄 시작 스코프"로, `_ASSIGN_RE` 키워드 경계, `if/for/while/switch` 는 블록으로, 여러 줄 템플릿 줄 마스크.
7. JS 2026-10-13 회귀(정화 헬퍼 TAINTED) 되돌리기: 반환식을 인자 상태로 치환해 분류.
8. 파일: 이름 기반 허용(`.env*`·`.npmrc`·`.pypirc`·`.netrc`·`.htpasswd`·`web.config`) + `.jsp/.ejs/.hbs/.ipynb`; 미니파이드 판정보다 비밀 특례·값 기반 룰을 먼저; 긴 줄 하나로 파일을 버리지 않기(줄 단위 제외); 해시 파일명에서 날짜 스탬프 제외; 제외 디렉터리도 기록.
9. 정규식: `[\s\S]{0,N}`·`\n` 패턴은 파일 단위 매칭 후 줄 번호 역산; `*/` 뒤 코드는 주석 아님; 비밀 어휘 확장(`*_SECRET_ACCESS_KEY`·`*_KEY`·camelCase·YAML).
10. 인텔: `scan --check-deps` 비차단 자동 갱신, 기본 신선도 2일, doctor WARN, 포털 일일 `intel-sync`.

### B. 판정 계층 단일화 (2~3일)
11. 값 기반·구문 약점·예외 목록을 **한 곳**(schema)에 두고 모든 감쇄가 참조. `_ENGINE_PRECISION`·`SEVERITY_RANK` 한 벌.
