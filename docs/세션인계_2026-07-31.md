  DDL/PRAGMA 는 별도 룰(`GOV-SQL-DDL-DYNAMIC-001`, medium)로 분리
- **무한 반복문 오탐 6/6 제거**: regex → AST 판정(탈출 경로·대기 인식)
- **내부망 IP 오탐 제거**: `exclude_patterns` 메커니즘 신설(전 룰 재사용 가능)

  꺼지던 문제. `utf-8-sig` 로 수정. Windows·한글 환경에서 흔함

- **침묵 제거**: 미검사 파일도 `skipped_files` 에 기록(3건 → 148건)

## 7. 작업 원칙 (이번 세션에서 지킨 것 — 계속 유지)

1. **도구의 주장을 그대로 옮기지 않는다** — 원본 소스에서 확인한 것만 판정으로 기록.
   (코덱스 지적 중 `.secret_key` 건은 검증 결과 **절반이 사실과 달랐음**)
2. **우리 도구의 오탐도 상용 도구와 같은 기준으로 기록한다** — 자기 도구에 관대한
   기록은 개선을 멈추게 함.
3. **과잉 교정을 경계한다** — 라운드5에서 `.html` 전체를 '문서'로 분류했다가
   Flask 템플릿의 CDN 로딩(폐쇄망 위험)을 숨기는 오류를 자체 발견·수정.
4. **실패는 올바른 곳에서 나게 한다** — 조용한 초록불이 빨간불보다 위험.
