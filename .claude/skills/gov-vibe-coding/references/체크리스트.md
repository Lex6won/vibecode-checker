# 단계별 마무리 체크리스트

각 단계 종료 시 사용자와 함께 확인한다. 빠진 게 있으면 그 단계로 되돌아간다.

## 1단계 · 기획 완료 체크
- [ ] 한 줄 정의가 명확한가
- [ ] 사용자(시민/내부/부서)와 **외부 공개 여부**가 정해졌나
- [ ] **데이터 등급**이 분류됐나 (고유식별/개인정보/내부/비밀값/공개)
- [ ] **운영 환경**(인터넷/망분리)이 정해졌나
- [ ] 외부 AI·외부 서비스 사용 여부가 정해졌나
- [ ] 핵심 기능이 1~3개로 좁혀졌나

## 2단계 · 설계 완료 체크
- [ ] 비전문가가 감당할 **단순한 구조**인가 (과한 아키텍처 아님)
- [ ] 데이터 흐름(입력→처리→저장→출력)에서 개인정보 경로가 표시됐나
- [ ] **보안 결정사항 표**가 데이터 등급에 맞게 채워졌나
- [ ] 비밀값은 환경변수/시크릿 매니저로 정해졌나
- [ ] 외부 egress(외부 API·LLM·패키지)가 목록화됐고, 망분리면 차단됐나
- [ ] (권장) `search_rules`로 관련 시나리오 룰을 미리 확인했나

## 3단계 · 보안점검 완료 체크
- [ ] `server_status`로 MCP 연결·룰 로드를 확인했나
- [ ] 코드/파일/의존성을 알맞은 도구로 점검했나 (`scan_code`/`scan_path`/`scan_dependencies`)
- [ ] **검사된 파일 수가 0이 아닌지** 확인했나 (0이면 경로 재확인)
- [ ] **critical/high·block** 항목을 모두 해결(또는 차단 결정)했나
- [ ] 각 항목에 **업무 영향 1줄 + 수정 방향**을 제공했나
- [ ] `render_report`로 한국어 보고서를 만들었나
- [ ] 마지막에 **기관 보안 담당자 확인**을 권고했나
