# 데이터 분류 가이드 (공공기관용)

기획 1단계에서 "어떤 데이터를 다루나요?"의 답을 아래 등급으로 분류한다.
**등급이 높을수록 설계·보안의 강도가 올라간다.** 비전문가에게는 "이건 ○등급이라 ○○를 꼭 해야 해요"로 설명한다.

## 등급 표

| 등급 | 예시 데이터 | 핵심 규칙 |
|---|---|---|
| **고유식별정보 (최고)** | 주민등록번호, 여권번호, 운전면허번호, 외국인등록번호 | 평문 저장·전송·로그 **금지**. 암호화 저장 + 화면·로그 **마스킹**. 테스트는 더미데이터(`123456-1******`). 외부 LLM 전송 **절대 금지**. |
| **개인정보 (높음)** | 이름, 연락처, 주소, 이메일, 생년월일, 민원인 정보 | 최소 수집·목적 외 사용 금지. 접근통제·접근로그. 외부 전송 시 마스킹. 개인정보 영향평가(PIA) 대상 여부 확인. |
| **민감/내부정보 (높음)** | 민원 내용, 결재·공문, 내부 통계, 비공개 행정문서 | 내부망 보관 원칙. 접근권한 분리. 외부 AI·외부 저장소 업로드 금지. |
| **비밀값 (높음)** | API 키, 비밀번호, 토큰, 인증서 키 | 코드 하드코딩 **금지** → 환경변수/시크릿 매니저. Git 커밋 금지. |
| **공개/일반 (낮음)** | 공개 통계, 보도자료, 일반 안내문 | 기본 보안만. 그래도 입력검증·XSS는 적용. |

## 빠른 판단 질문

- "이 화면/파일에 **이름+다른 정보**(연락처·주소 등)가 같이 보이나?" → 예: 개인정보 이상.
- "**주민번호·여권번호** 같은 게 들어가나?" → 예: 고유식별정보(최고 등급).
- "**민원·결재·공문** 내용이 들어가나?" → 예: 내부정보.
- "**외부 인터넷**에 공개되나, **내부 행정망**에만 있나?" → 망분리면 외부 통신 전면 차단.

## 등급 → 설계 연결

분류 결과를 `templates/기획서.md`의 "데이터 등급"에 적고, 2단계 설계의 "보안 결정사항 표"에 그대로 반영한다.
관련 MCP 룰: 주민번호 `GOV-PII-RRN-001`(block), 외부 AI 전송 `GOV-LLM-PII-PROMPT-001`(block).

> 주의: 이 분류는 실무 보조용이다. 실제 등급·법적 의무(개인정보보호법, 기관 내규)는 기관 개인정보·보안 담당자 확인이 우선이다.
